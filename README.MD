# About

A WordPress Theme for Suzanne Clothier using [TailwindCSS](https://tailwindcss.com/), with [PostCSS](https://postcss.org) and [Laravel Mix](https://laravel-mix.com/).

## Getting started

- Clone repo `git clone https://developer_slant@bitbucket.org/developer_slant/suzanneclothier.git && cd suzanneclothier`
- Run `npm install`
- Run `npm run development` or `npm run watch` to start developing

You will find the editable CSS and Javascript files within the `/resources` folder.

### Define theme colors

Four colors (primary, secondary, dark and light) are defined from the beginning. You can modify the colors in `twp.json`.

### Define theme font sizes

You can modify the font sizes within `twp.json`.

## PurgeCSS

By default, PurgeCSS is enabled. You can modify or disable it by changing the settings in the `tailwind.config.js` file. There are several [PurgeCSS options](https://tailwindcss.com/docs/optimizing-for-production#purge-css-options).
